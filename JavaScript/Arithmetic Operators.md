## Arithmetic Operators
***These operators are used for performing mathematical operations.***

 ### ✅list of Arithmetic Operators
```
+	Addition
-	Subtraction
*	Multiplication
**	Exponentiation (ES2016)
/	Division
%	Modulus (Remainder)
++	Increment
--	Decrement
```
### ➡️Example of Arithimetic Operators
```
let sum = 5 + 10; // 15
let difference = 15 - 5; // 10
let product = 4 * 5; // 20
let quotient = 20 / 4; // 5
let remainder = 10 % 3; // 1
let power = 2 ** 3; // 8

let num = 5;
num++; // 6

let num = 5;
num--; // 4

```
### ✅ Assignment Operators in JavaScript



**✅ Assignment (=)**
```
let x = 10;
console.log('Assignment (=):', x); // Output: 10
```

**✅ Addition assignment (+=)**
```
let a = 5;
a += 3; // Equivalent to a = a + 3
console.log('Addition assignment (+=):', a); // Output: 8
```

**✅ Subtraction assignment (-=)**
```
let b = 10;
b -= 4; // Equivalent to b = b - 4
console.log('Subtraction assignment (-=):', b); // Output: 6
```

**✅ Multiplication assignment (*=)***
```
let c = 7;
c *= 2; // Equivalent to c = c * 2
console.log('Multiplication assignment (*=):', c); // Output: 14
```

**✅ Division assignment (/=)**
```
let d = 20;
d /= 4; // Equivalent to d = d / 4
console.log('Division assignment (/=):', d); // Output: 5
```

**✅ Modulus assignment (%=)**
```
let e = 17;
e %= 5; // Equivalent to e = e % 5
console.log('Modulus assignment (%=):', e); // Output: 2
```

**✅ Exponentiation assignment (**=)**
```
let f = 3;
f **= 2; // Equivalent to f = f ** 2
console.log('Exponentiation assignment (**=):', f); // Output: 9
```

**✅ String concatenation assignment (+=)**
```
let str = 'Hello';
str += ' World'; // Equivalent to str = str + ' World'
console.log('String concatenation assignment (+=):', str); // Output: "Hello World"
```

**✅ Comma operator in an assignment context**
```
let g;
g = (2 + 3, 4 + 1); // Evaluates to the value of the last expression (4 + 1)
console.log('Comma operator in an assignment context:', g); // Output: 5
```
